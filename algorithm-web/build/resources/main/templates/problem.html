Input format help
  • int[]: numbers separated by commas, e.g. 1,2,3 or [1,2,3]
  • int[][]: a grid, e.g. [ [1,2], [3,4] ]
  • String[]: words separated by commas, e.g. hello,world
  • int: one number, e.g. 42
  • String: text, e.g. hello
  • char[]: characters, e.g. a,b,c or abc
